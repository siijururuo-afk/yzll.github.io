## 排版审计

- 采用源文件中每个正文段落的原始顺序记录 `sourceIndex`，保留非空文本与空白结构，不把两个段落擅自合并。
- 从源 `p` 节点的样式读取空段的 `min-height` 和 `margin-top`，在 JSON 的 `spacerHeight` 保存原始留白高度，避免通用阅读器把大段空白压缩。
- 原文中的斜体与对齐记录在段落样式信息中；第 1、7、10 章有视频嵌入。
- 离线文件中没有可恢复的 `img` 标签，不能断定原作者网页没有图片。
- 角色名统一为曹承衍（조승연）、金宇硕（김우석），舞台艺名 `우신` 译为“宇信”。
- 仅显示中文版，但保留正文的来源顺序、中文与韩文对应索引，以及原有媒体位置。
- 十个章节以 gzip 压缩 JSON 提供，依赖现代浏览器的 `DecompressionStream('gzip')`。

## 2026-11-16 版式专项复核与修正

重新对照本次用户提交的 10 份原文 HTML（正文结构与之前的原文一致）。此前的验证主要确认文字和 DOM 节点数，并不证明视觉排版一致。逐段检查发现旧阅读器通用 CSS 会让本作品失真：

- **源文格式**：18px 字号、31.5px 行高，普通非首段上边距为 18px、每个 p 的最小高度为 30.6px；每章第一个 p 上边距为 0。原本每个普通空白段落实际占用 **48.6px**，这一高度已记录在章节 JSON 的 `spacerHeight` 中。
- **网站旧格式**：通用正文行高为 1.95 倍（18px 时 35.1px），正文 p 另有 1.3em 下边距，并采用通常的 `story-par` 布局；与源文每段仅 18px 上边距的布局不同。媒体 iframe 的外边距原为 25px / 42px，而原文 figure 只有 18px 上边距。
- **已修正**：阅读器只为 `animato-1` 至 `animato-10` 添加源式排版 CSS（固定原文比例 1.75 行高，正文上边距 18px、空白高度仍按原记录、媒体只有 18px 上边距）；用 `sourceIndex` 精确定位原文首段及第 1、10 章特殊的右对齐斜体衬线字体。未修改正文翻译、空白数量和视频文件。
- **限制**：原文首段的 Nanum Myeongjo 和末尾的 KoPub Batang 字体以系统备用衬线字体回退，不附带原文嵌入字体；尚未进行所有手机型号的逐像素截图比较。
