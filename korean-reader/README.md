## 原文与排版

所有新导入的小说按 [IMPORT_RULES.md](IMPORT_RULES.md) 审计原始 HTML 的标题、空行、缩进、对齐、聊天气泡、图片和嵌入媒体。无法恢复的图片必须注明，不生成假图。旧有小说中的原文图片和 YouTube 嵌入按原有数据位置展示。

`index.html`、`app.js`、`style.css` 是静态阅读器；`stories/*.json` 保存中文译文和已有原文结构信息。阅读进度继续沿用此前 `between-lines-v2` 的本地存储键；旧语言偏好会被忽略，统一打开中文。
