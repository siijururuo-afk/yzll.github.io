# 문장 사이 · 私人小说阅读书架

白底黑字个人阅读站。默认**英文阅读、中文隐藏**。顶部「显示全部中文 / 收起全部中文」可一键切换全章，每个英文段落底部「显示中文 / 收起中文」可单独切换，英文始终保留。用户原有中文优先模式会自动迁移一次，之后尊重手动选择。点词功能保留，点击英文可查中文释义、IPA 音标、原句并加入生词本。

## 隐私提醒

GitHub Pages 是静态公开托管。仓库公开时正文和译文也可被读取，普通前端密码弹窗并非加密措施。如需仅供自己访问，应迁移到需要身份验证的后端或在上传前加密正文，并清理 Git 历史中的明文。

## 网站文件

`index.html`、`style.css`、`app.js` 负责界面与交互；`stories/*.json` 保存各章韩中英对照数据。支持按系列分组、章节切换、字体调整、每章阅读位置保存与翻译状态提示。

## 英语点词功能（2026-10-29）

内置 14,587 条英汉词汇，常见英文单词即点即显示中文释义。原有韩语点词、英文音标、朗读、上下文和收藏功能保留。未收录词汇仍可联网查询，4.5 秒超时后提示无法获取，避免无限加载。部分音标仍需联网补充。

词汇数据来源：KyleBing/english-vocabulary（依据 ECDICT 整理），ECDICT：https://github.com/skywind3000/ECDICT（MIT）。

## 阅读模式更新（2026-10-30）

默认进入「英文＋可展开中文」，不开中文时只显示英文；每段的中文可以独立展开或收起；最上方按钮可统一切换整章的中文显示状态，覆盖之前的逐段例外。切换时不会重新加载文章或清空生词与阅读进度。其他韩语及三语模式仍在「语言」菜单中。
