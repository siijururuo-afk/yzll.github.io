## 为新章节添加译文

在「更多 → 翻译设置」中填写自己的 OpenAI 兼容翻译 API 地址、模型与临时密钥，打开需要翻译的章节，点击「翻译本章缺失的中英文」。翻译完成后可以在本设备直接阅读中文并使用语言对照。译文按段缓存在当前浏览器 localStorage，不会提交到 GitHub，也不会自动同步到其他设备；清理网站数据后可能丢失。没有翻译服务的密钥，网站不会凭空自动翻译。翻译 API 可能产生费用，请注意服务条款。
